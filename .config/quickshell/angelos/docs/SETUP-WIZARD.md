# Мастер первого запуска

Как устроен (2026-10-04) и что было не так со старым мастером из 14 шагов.

## Как устроен

- `modules/settings/SetupFlow.qml` — ход мастера: вопросы по порядку (данные `stepList`), какой сейчас,
  чем кончается («Начать работу», «Закрыть» при повторном запуске, `angelos setup skip`), когда
  открывается сам.
- `modules/settings/SetupWizard.qml` — всегда на весь экран (2026-10-07): накрывает каждый экран
  (layer shell, overlay, клавиатура — Exclusive), на одном — вопросы, на остальных — где они и
  «Продолжить на этом экране». Первый запуск выйти не даёт: ни «Настроить позже», ни Esc — только
  пройти до конца; внизу подсказка про `angelos setup skip` из текстовой консоли. Повторный запуск
  (Настройки → Аккаунт, `angelos setup`) — тот же экран, но с «Закрыть» и Esc; Настройки, открытые
  до него, возвращаются после.
- Клавиши niri тоже ждут: `ShortcutInhibitor` на окне с вопросами (Mod+T, Mod+Q, столы и т. п.
  уходят в мастер, а не в niri). Проходят только бинды с `allow-inhibiting=false`: медиаклавиши и
  громкость, Mod+Escape. Mod+Escape выключает ингибитор — мастер тут же просит его снова; если
  оболочка зависла, просить некому, и Mod+Escape возвращает niri. Во вложенном/dev-запуске
  (`ANGELOS_DEV=1`) ингибитора нет.
- `modules/settings/SetupAssistant.qml` — сами вопросы, раскладка как у OOBE Windows 11 / macOS
  (2026-10-07): слева картинка шага (следует за ответом: ангел или окно, тема, Golden Gate, движение),
  справа «Шаг N из M», крупный заголовок, строка, ответ карточками, под ним прогресс и «Назад» /
  «Продолжить». На высоком экране картинка сверху. Большой экран с мелкими пикселями — вся сцена
  ×2/×3 без сглаживания. Снимки: `ANGELOS_TEST_SHOTS=dir scripts/test-ui.sh` → `setup-*.png`. Грузится отдельно: если в нём ошибка, экраны отпускаются.
  В самопроверке (`scripts/test-ui.sh`, без layer shell) его держит окно `tests/ui/Driver.qml`.
- `Shell.setupLocked` (= мастер открыт) — рабочий стол держится: «Пуск», лаунчер, буфер, меню
  питания, Настройки, Alt+Tab, заставка, всплывающие уведомления, окно «перезапустить после
  обновления» и горячие клавиши оболочки (функции `Ipc.qml`, которые зовут бинды niri) ждут.
  Громкость и медиаклавиши работают.
- `angelos setup skip` (`scripts/setup-cli.py`) — сначала метка `~/.config/angelos/setup-skipped`
  (оболочка, запущенная после этого, экран не закроет), потом просьба к работающей оболочке
  (`qs ipc --any-display`: из текстовой консоли нет WAYLAND_DISPLAY). Тесты: `tests/setup/test_cli.py`.
- Шаг с группой из Настроек называет её блоком дерева (`"blocks": ["keyboard/keyboard-layouts"]`);
  страница находится по дереву (`SettingsTree.blockPart`), куда бы её ни переставили в `tree.json`.
  `tests/settings/test_tree.py` проверяет, что такие блоки есть в дереве.
- Установщик пишет `setup.gameAsked` и `setup.keyboardAsked`; с 2026-10-07 мастер эти шаги не
  пропускает, а показывает уже выбранный ответ.
- «Смотри сюда» — пульсирующая пиксельная обводка с ярлычком: сначала вокруг ответа («сюда ♡»),
  после выбора (или через 6 с — значение по умолчанию тоже годится) — вокруг «Продолжить»
  («дальше ♡»). При выключенном движении обводка стоит на месте.
- GitHub (`SetupGitHub.qml`, живёт в SetupFlow, чтобы вход шёл при смене шагов): `gh auth login
  --web` без браузера — код крупно и QR на github.com/login/device для телефона (`qrencode`, если
  есть). Дальше `scripts/author-tools.sh` (status/fetch): owner/ из закрытого репо и метка
  `~/.config/angelos/owner`, потом `Owner.refresh()` — админ-функции включает только ответ GitHub
  (`scripts/owner-check.sh`). Шага нет, если не установлен gh. Кнопка — «Пропустить», пока вход
  не завершён.

Шаги сейчас (2026-10-07, до тринадцати): **Привет** (язык) → **Откуда ты пришёл** (Windows: три кнопки
окон; macOS: Golden Gate + клавиши Mac по желанию; Linux; впервые; `setup.from` меняет подсказки дальше) →
**Игра или просто рабочий стол** → **Главный экран** (если экранов несколько) → **Раскладки** (группа из
Настроек) → **Мышь и тачпад** → **Как здесь живут окна** (лента niri: новые окна по половине или во весь
экран) → **Светлая или тёмная** → **Обои** (обои релиза — дневной или ночной вариант под тему, — потом
картинки из ~/Pictures; шага нет без картинок) → **Сколько движется** → **Кто ты?** (Стример, Работяга,
Обычный чел, Творческая деятельность: `setup.persona`, отмечает программы) → **Какие программы
поставить?** (браузер Helium/Firefox и остальное из `data/apps-catalog.json`; уже стоящие с ✓, чего нет в
репозиториях — бледное; `setup.apps`) → **GitHub** (вход через gh; сохранение и восстановление прогресса и
настроек — services/Recovery, приватный репозиторий angelos-save; найденное сохранение — «Восстановить
и перезапустить») → **Всё готово**. После «Начать работу» отмеченные программы ставятся в терминале
(`scripts/apps-install.py install …`: pacman → AUR через paru/yay → Flathub, sudo спрашивает пароль).
