# Мастер первого запуска

Как устроен (2026-10-04) и что было не так со старым мастером из 14 шагов.

## Как устроен

- `modules/settings/SetupFlow.qml` — ход мастера: вопросы по порядку (данные `stepList`), какой сейчас,
  чем кончается («Начать работу» или «Настроить позже»), когда открывается сам. Здесь же окно для
  повторного запуска.
- `modules/settings/SetupWizard.qml` — первый запуск: накрывает каждый экран (layer shell, overlay),
  на одном — вопросы, на остальных — где они и «Продолжить на этом экране». «Настроить позже», Esc и
  подсказка про `angelos setup skip` — на каждом экране, вне файла с вопросами.
- `modules/settings/SetupAssistant.qml` — сами вопросы: картинка, крупный заголовок, строка, ответ
  карточками, «Назад» / «Продолжить». Грузится отдельно: если в нём ошибка, экраны отпускаются.
- `Shell.setupLocked` — рабочий стол держится: «Пуск», лаунчер, буфер, меню питания, Настройки,
  Alt+Tab, заставка, всплывающие уведомления, окно «перезапустить после обновления» и горячие клавиши
  оболочки (функции `Ipc.qml`, которые зовут бинды niri) ждут. Громкость и медиаклавиши работают.
- `angelos setup skip` (`scripts/setup-cli.py`) — сначала метка `~/.config/angelos/setup-skipped`
  (оболочка, запущенная после этого, экран не закроет), потом просьба к работающей оболочке
  (`qs ipc --any-display`: из текстовой консоли нет WAYLAND_DISPLAY). Тесты: `tests/setup/test_cli.py`.
- Шаг с группой из Настроек называет её блоком дерева (`"blocks": ["keyboard/keyboard-layouts"]`);
  страница находится по дереву (`SettingsTree.blockPart`), куда бы её ни переставили в `tree.json`.
  `tests/settings/test_tree.py` проверяет, что такие блоки есть в дереве.
- Установщик пишет `setup.gameAsked` и `setup.keyboardAsked`, если спросил игру и раскладки, —
  на первом запуске мастер эти шаги пропускает.

Шаги сейчас: **Привет** (язык) → **Игра или просто рабочий стол** → **Главный экран** (если экранов
несколько; виджеты едут туда же) → **Раскладки** (группа из Настроек) → **Светлая или тёмная** →
**Сколько движется** → **Всё готово** (Mod+Space, Mod+S, Mod+Shift+Escape и экскурсия по панели).
