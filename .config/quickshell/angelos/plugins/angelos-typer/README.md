# Бумажки Typer — плагин 0.4.3

На панели — маленькая иконка бумажки, без надписи. При наведении она мягко
подсвечивается, при открытии слегка поворачивается. Маленькая точка показывает,
что на рабочем столе есть заметки.

1. Нажми иконку: откроется небольшое окно с полем текста.
2. Напиши заметку и нажми «Прикрепить» или Ctrl+Enter.
3. Бумажка появится на рабочем столе. Тяни её за любую часть в удобное место.
4. Три быстрых левых клика убирают бумажку. Двойной клик её оставляет.

Если передумал, открой иконку и нажми «Вернуть». Последние 20 убранных заметок
сохраняются для возврата. После успешного возврата окно ввода закрывается,
освобождая захват ввода для перетаскивания бумажки.
Перетаскивание не засчитывается за клик удаления.
Длинную заметку можно прокручивать колёсиком или вертикальным жестом тачпада.

Закрытие окна ввода оставляет черновик. Текст, бумажки и их положение переживают
перезапуск оболочки. Полный редактор открывается через меню приложений, лаунчер
настройки плагина или кнопку «Открыть Typer» в окне заметки.

## Хранение

Используются штатные API плагинов и DesktopWidgets, без изменений ядра angelOS.
Бумажки — элементы `desktop.widgets` типа `plugin:angelos-typer` с текстом
в `settings.text`. Черновик и архив — namespace плагина в `plugins.data.angelos-typer`.
Всё находится в `~/.config/angelos/settings.json`, который сохраняет сама оболочка.
Отключение плагина скрывает бумажки, не стирая данные. Для одной бумажки — до 8000
символов. Не очищать настройки плагина при обновлении.

## Темы и жизненный цикл

Skin API задаёт цвета, размеры, шрифты и длительность анимаций. Pixel использует
пиксельную иконку, Golden Gate — контурную. Окно ввода — штатный BarPopup,
создаваемый через LazyPopup. Таймеров и процессов для закрытого окна нет.
Бумажки размещает штатный хост desktopWidget. Перетаскивание у них свободное:
они следуют указателю без округления к сетке и отталкивания от других виджетов.
Передний план многослойных обоев может перекрывать до 20% бумажки (обычная глубина).
Во время перетаскивания она поднимается над сценой, как остальные виджеты.
Их содержимое использует бумагу с загнутым уголком и полоской скотча. Переходы
учитывают выключенную анимацию системы.

## Обновление

Плагин и редактор обновляются вместе с angelOS.

## Проверка движения в 0.3

Проверен путь из нескольких событий мыши, включая малые смещения. На каждом шаге
реальная позиция совпала с ожидаемой, без скачков к сетке. Проверены ограничения
краями экрана и сохранение свободных координат. Поведение прочих виджетов и
настройка общей сетки не менялись.

## Фокус и панель в 0.4

Обводка Typer использует штатный PxButton, как встроенные кнопки панели.
Пока открыт composer, плагин временно получает WlrKeyboardFocus.Exclusive
для родительской панели; при закрытии Binding восстанавливает прежний режим.
Это позволяет настоящей клавиатуре попадать в поле, а не в последнее приложение.
Проверено вводом wtype в работающей сессии и возвратом фокуса после Escape.
Кнопка «Открыть Typer» закрывает popup перед запуском полного редактора.
«Вернуть» находится отдельной строкой, чтобы надписи помещались.
Существующие бумажки с deep переводятся в обычную глубину при загрузке;
новые сразу получают предел 20%. Режим «Поверх» сохраняется.


## Иконка панели в 0.4.2

В пиксельной теме иконку заметки рисует штатный `PxButton { icon: "note" }`:
палитра, выбранный набор значков и адский облик берутся из оболочки. В Golden Gate
остаётся одноцветный `MacIcon` через TyperGlyph, с цветом `Skin.ink(screenName)`.
Кнопка, popup и данные заметок сохраняют прежнее поведение. Правила автора —
`docs/PLUGINS.md`, раздел Theme API, и `plugins/_template/BarWidget.qml` оболочки.


В 0.4.3 контурная иконка Golden Gate использует существующее имя `file-text`
из MacIcons.js. Прежнее `sticky-note` отсутствовало и давало circle-help.
